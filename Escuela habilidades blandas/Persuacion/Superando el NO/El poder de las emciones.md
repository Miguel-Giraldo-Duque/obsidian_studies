


### Como funciona el cerebro ?


El cerebro se basa en dos sistemas el primero un sistema emoción rápido desarrollado para la acción y este domina al 2 sistema el cual se refiere a nuestro pensamiento racional por ello en la [[Persuacion]] si logramos impactar a este cerebro emocional convenceremos significativamente mejor al objetivo
cosas como :


«¿Cómo se supone que voy a hacer eso?»


Sin embargo sin la capacidad de leer el sistema 1 de las personas resulta imposible controlar el sistema 2
