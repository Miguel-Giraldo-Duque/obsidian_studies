

## Que es un componente 



Un componente en [[Escuela desarrollo web/JS/React/React]] funciona como una pieza ensencial que nos permite contruir una estructura mas grande como lo podria ser una pagina web   , por ejemplo un componente de mi pagina web podria ser mi navbar , mi footer , e incluso mi navBar podria tener otro componente por dentro como un btn 

El objetivo final de los componentes en react es funcionar coomo fiezas desarmables ,adaptables, y escalebles  a lo largo del tiempo en nuestras aplicaciones web .




Ademas los componentes  nos permiten trabajar con una metodogia de trabajo mucho mas inteligente que habla de entrega de productos minimos como vemos aqui
