
## Como es?


### ****Server Side Rendering - SSR**** ?


Inicialmente nuestro  usuario entraría a un navegador donde va buscar alguna url o alguna pagina como YouTube o  lo que sea  , el servidor de esa pagina nos devuelve un resultado en HTML dependiendo de la solicitud que le hallamos hecho 


### Single Page Application

Una Single Page Application (SPA) es un enfoque de desarrollo de aplicaciones web que implica cargar una única página HTML en el navegador del usuario. En lugar de recargar completamente la página cada vez que se realiza una interacción, las SPA utilizan JavaScript para enviar solicitudes a una [[Api rest]] en el backend de la aplicación.

Cuando el servidor responde con los datos solicitados, la SPA utiliza estos datos para manipular el Document Object Model (DOM) y actualizar la página de forma dinámica. Esto permite crear aplicaciones web altamente interactivas y fluidas, ya que solo se cargan los datos necesarios en lugar de cargar una página completamente nueva.

Al cargar una vez el HTML inicial y realizar solicitudes a la API REST para obtener datos o realizar acciones, las SPAs brindan una experiencia de usuario más rápida y fluida, similar a una aplicación de escritorio, sin la necesidad de recargar constantemente la página.
