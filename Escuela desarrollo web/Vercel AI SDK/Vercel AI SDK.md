### ¿Qué es?

Es una **librería** para trabajar con las herramientas tradicionales de AI de una forma fácil, ya integrando muchas de las funcionalidades complejas.

**Vercel AI Core**: tools, generación de texto, RAG e incluso agentes.

**AI SDK UI**: para crear hooks y crear chats y UI generativa.

**AI SDK RSC**: está especializado en Server Components.
