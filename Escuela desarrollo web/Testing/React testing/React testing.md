
### Como se hace?

El [[Testing]] es calve para identificar errores y minimizar el impacto que estos causan, en el fronted esto es clave a tener en cuenta y pueden ser un factor muy útiles cuando queremos automatizar revisiones .

Para hacerlo en [[React]] instalamos la siguientes dependecias:

- `@testing-library/dom` : Nos permite crear entornos virtuales donde podemos simular una interacion con el navegador

- `@testing-library/jest-dom` : Nos permite una serie de funciones para la búsqueda y matches en nuestro código facilitando la reviso

- `@testing-library/react` : Esta es la librería robusta de teting para react que nos ofrece facilidad para ejecutar test en componentes 

- `jsdom` :  Otras facilidades para construir mejor la UI.

- `vitest` :  Es el runner de test
