

## Que son?



Son todas aquellas funcionalidades que Node de forma predeterminada trae 
sin tener que la necesidad de importarlas por ejemplo set Interval , el console.log, el requiere etc



## Preguntas

  
##### Y por que se pueden usar estas funcionalidades en el navegador incluso si no tengo instalado Node?


Por que al igual que Node.js, los navegadores web proporcionan un conjunto de funcionalidades integradas que están disponibles automáticamente en el entorno de JavaScript del navegador. Esto incluye funciones como `console.log`, `setTimeout`, `alert`, entre otras.
