
### Que es?

Una base de datos tiene un origne anestral en los seres humanos en busqueda persistir y tramitar a informacion , fuimos de boca en bca , del papiro al papel , de la cinta al disco , y al final con la llegada del cloud una herramienta para cceder desde cualquier parte dle mundo a una misma data las bases de datos vienen estas tienen ventajas claves:

**Permiten percistir datos en el cloud** : Nos permite almacenar neustros datos en las computadores del cloud para mantener los registro 


#### Que tipos hay?
- **Bases de Datos Relacionales (SQL)**:
    
    - Almacenan datos en tablas (filas y columnas) con relaciones definidas.
        
    - Ejemplos: MySQL, PostgreSQL, Oracle.
        
    - Ventajas: Estructura rígida pero consistente, ideal para transacciones complejas.
        
- **Bases de Datos No Relacionales (NoSQL)**:
    
    - Flexibles, sin esquema fijo. Ideales para datos no estructurados (JSON, documentos, grafos).
        
    - Ejemplos: MongoDB (documentos), Redis (clave-valor), Neo4j (grafos).
        
    - Ventajas: Escalabilidad horizontal y adaptabilidad a cambios en los datos.
        

##### **2. Según su Gestión**

- **Auto-administradas (Managed)**:
    
    - El proveedor cloud (AWS, Google Cloud, Azure) se encarga de mantenimiento, actualizaciones y escalado.
        
    - Ejemplos: Amazon RDS, Firebase, MongoDB Atlas.
        
    - Ventaja: Menor carga operativa para el usuario.
        
- **Administradas Manualmente**:
    
    - Requieren configuración, mantenimiento y actualizaciones manuales (ej: instalar MySQL en un servidor propio).
        
    - Ventaja: Mayor control sobre la configuración y recursos.
