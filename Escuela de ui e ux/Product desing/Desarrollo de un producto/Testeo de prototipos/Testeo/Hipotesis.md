### Creación de hipótesis como hacerla?


Una buena hipótesis consta de las siguientes partes para ser considerada una  buena hipótesis  

- [ ] Es simple
- [ ] Es medible
- [ ] Tiene una causa y efecto
- [ ] Se puede demostrar que es falsa  -- Karl Poper
- [ ] Es alcanzable
- [ ] Es clara
