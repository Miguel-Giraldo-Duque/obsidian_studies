
## Como funciona?

Es una tecnica para el testing de [[Flujos de sistemas de conversacion]] donde evaluamos con nuestra [[Creación de diálogos]] una simulación entre la interacción de nuestro [[System Persona]] con nuestro usuario pero seremos nosotros quienes actuaran como nuestro sistema respondiendo como el sistema todo con el fin de captar la mayor cantidad de información posible de como la persona interactúa con nuestro sistema y que lenguaje usa .

Se busca que el entrevistador este en otra habitación simulando los comandos
