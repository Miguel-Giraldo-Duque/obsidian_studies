### Que es?

Los principios de espaciado son útiles , para mostrarle al usuario Relacion entre elementos cuanto mas cerca un elemento entre otro podemos experimentar que están mas relacionados con otro

Todos los elementos  en nuestra [[Interfaz]] , están relacionados independientemente de su distancia en la pantalla mientras están relacionados lo importante recae en la fuerza de las relaciones entre estos elementos

1.  Mientras mas cerca los elementos mas los consideramos de un mismo conjunto por ejemplo un titulo a un subtitulo tienen un Relacion profunda 
![[Pasted image 20241127174514.png]]
Si quisiéramos que no estuviesen relacionados deberíamos separarlos mucho mas para aislarlos , por ejemplo si vemos este ejemplo entendemos que esta es una Relacion mas débil dado la distancia entre los elementos


![[Pasted image 20241127174652.png]]

Cuando percibimos elementos como relacionados al aislarlos demasiado creamos una sensación incomoda a la vista pues reconocemos el sol como parte del mensaje pero esta demasiado lejos para percibirlo como parte de ese conjunto 
![[Pasted image 20241127174917.png]]
