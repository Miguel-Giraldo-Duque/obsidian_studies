

### Que es?


SLQ es un lenguaje que se instauró como una forma de estandarizar como consultábamos las [[Bases de datos]] , y obteníamos la informacion , con el tiempo se volvió el estándar de trabajo y ahora muchas empresas y bases de datos la usan como referencia o como lenguaje .

Exceptuando bases de datos como [[MongoDb]] noSQL que si mantienen la estrutura de SQL pero tienen mucha mas flexibilidad
