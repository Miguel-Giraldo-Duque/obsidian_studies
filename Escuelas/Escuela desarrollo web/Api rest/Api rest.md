

## Que es una Api rest 


Una [[Apis]] REST (Representational State Transfer) es una interfaz que permite la comunicación entre sistemas o aplicaciones utilizando el protocolo HTTP. A diferencia de las APIs convencionales, que están diseñadas para la comunicación entre robots, las APIs REST están destinadas a la comunicación entre sistemas informáticos a través de la web.

Estas APIs utilizan los métodos HTTP, como GET, POST, PUT y DELETE, para realizar operaciones sobre los recursos expuestos por el sistema. Además, las respuestas y solicitudes se suelen intercambiar en formato JSON , aunque también se pueden utilizar otros formatos.

En resumen, una API REST es una interfaz que permite a un sistema interactuar con otro a través de HTTP, utilizando métodos estándar y formatos de intercambio de datos comunes como JSON.
