


## Como funcionan ?


todo lo que involucra el rango de 200 quiere decir que el backend y fronted hubo un éxito 


Con la centena de los 300 significa redirect


La centena 400 un error que cometimos como fronted 


Centena 500 el backend fallo (Por demasiadas solicitudes )



- **1XX** Respuestas Afirmativas
    
- **2XX** Respuestas satisfactorias
    
- **3XX** Re-direcciones
    
- **4XX** Error del cliente
    
- **5XX** Error de servidor
