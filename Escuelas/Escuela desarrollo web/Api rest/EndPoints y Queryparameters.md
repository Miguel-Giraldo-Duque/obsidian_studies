


## Que son?



Un EndPoints son rutas que nos permiten acceder a partes especificas de una [[Apis]] que nos puedan devolver una información en base a esa ruta que le dimos , mismas que dependerán de la documentación de la api


ejem :

	api.com/images
	api.com/categories
	api.com/images/michi34


### Queryparameters 

Son  con las que podemos limitar el contenido que recibimos de nuestra api  donde algunas Apis podremos poner un limite a la cantidad de datos que recibimos , o poner un tipo de valor especifico que queramos que nos devuelvan 


ejem
	/categories?serach=fun 
	/images?categories=3                 


Al igual que con los EndPoints los Queryparameters dependerán de la documentación de cada api
