


## Que es una api?


Una api es la forma a en que podemos apoyarnos y conectarnos con otras empresas para enriquecer nuestras aplicaciones donde por ejemplo : si yo quisiera hacer un aplicación como Uber , crear los mapas por mi mismo seria increíblemente caro muy diferente si me conectara a los mapas de Google maps que ya han hecho ese trabajo por mi 



### Que es una interfaz ?

Una interfaz es la forma en la que me puedo comunicar con un sistema sin necesidad de tener que saber esta pasando debajo  de esta interaccion ejemplo :
