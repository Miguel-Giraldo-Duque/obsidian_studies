## Que es?

NPM es un gestor de dependencias  que nos permite acortar el trabajo  utilizando herramientas que otros programadores desarrollaron  como gestores de fechas , datos etc. . 



### Como se usa npm 


npm cuenta con una serie de comandos básicos para su uso  

inicialmente para crear un paquete simplemente debemos decir " npm init " seguido de esto nos aparecerán una serie de preguntas sobre la creación del paquete 


- **name”: “npm-init”** —> Podemos ponerle un nombre sin embargo toma por defecto el de la carpeta.
    
- **“version”: “1.0.0”** —> Podemos cambiar segun el caso, dependiendo un cambio mayor o uno menor
    
- **“description”:""** —> Podemos hacer una breve descripcion del proyecto.
    
- **“entry point”: “(index.js)”** —> Punto de entrada del proyecto.
    
- **“test command”:** —> Podemos incluir los comandos para validar nuestro codigo.
    
- **“git repositorio”:** —> Podemos incluir el repositorio para mantenerlo en la nube
    
- **“keywords”: [“javascript”, “angular”, “node”]** —> Que va a utilizar nuestro proyecto.
    
- **“autor”: "Alexa Pulido<pulidoaleXXXXXXX>** —> Persona que crea el proyecto
    
- **“license”: “MIT”** —> Licencias, la mas utilizada es MIT, permite distribuir nuestro codigo.


Pero para créalo de forma rápida podemos usar el "npm init -y" comando que nos crea el archivo automáticamente  sin tener que responder las preguntas
