
### Que es?

La propuesta es simple, las contraseñas tienden a ser vulnerables un leak de información , un contraseña débil o diferentes factores influyen en que no es el factor  mas confiable.

por ello podemos usar one time password, es una estrategia que genera contraseñas por un tiempo limitado de 1min  estas contraseñas son generadas criptográficamente seguras, volviéndolas una herramienta muy viable para mantener la integridad en nuestros sistemas 


Algunas de estas herramientas son el autenticar de google o el que usa github para verificar nuestra identidad.
