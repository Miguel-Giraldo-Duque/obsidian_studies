
### Como funcionan?

En [[Escuelas/Escuela desarrollo web/Sass/Sass]] las variables funcionan como un método para mantener maxima consistencia en un sistema de diseño permitiéndonos crear sistemas de espaciado  colores , tamaños que podremos compartir en las hojas de estilo :

el archivo que tiene las vairbale debe contener un "__" al incio del nombre del archivo para indicar a Sass que es un archivo de variables

// $nombreMivar: valor
`$color-fondo: #4be50eff`

`$color-texto: #333333`

`$color-primario: #0070f3`

`$color-secundario: #ff4081`
