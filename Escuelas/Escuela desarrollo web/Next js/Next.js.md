
## Que es? 

Next js es un framework de react que busca crear componentes en el servidor (serveless) para optimizar el performace en la carga recurrente de componentes al precontruilas o crealas desde el lado de un servidor, es especialmente util cuando se requiere soluciones performantes y se necesita

- Priorizar SEO
- Velocidad 


Su principal fortaleza reside en el 
###### . **Renderizado Híbrido:**

- **SSG (Static Site Generation)**: Páginas pre-construidas en tiempo de build
    
- **SSR (Server-Side Rendering)**: Páginas renderizadas en cada request
    
- **CSR (Client-Side Rendering)**: Renderizado en el navegador (como [[React]] tradicional)
