```dataviewjs
let hoyStr = dv.current().file.name;
let fechaNota = moment(hoyStr, "YYYY-MM-DD");

if (fechaNota.isValid()) {
    let numeroSemanaISO = String(fechaNota.isoWeek()).padStart(2, '0');
    let nombreSemana = fechaNota.format("YYYY") + "-W" + numeroSemanaISO;
    let sem = dv.pages("#sprint/semanal").find(p => 
        p.file.name.toLowerCase().includes(nombreSemana.toLowerCase())
    );

    if (sem) {
        let cache = app.metadataCache.getFileCache(
            app.vault.getAbstractFileByPath(sem.file.path)
        );

        // Recolectamos todas las fechas de headings que sean anteriores a hoy
        let headingsAnteriores = (cache.headings || [])
            .map(h => h.heading)
            .filter(h => {
                // Extraemos fecha del heading (formato: "2026-06-05" o "2026-06-05 - Friday")
                let match = h.match(/^(\d{4}-\d{2}-\d{2})/);
                if (!match) return false;
                let fechaHeading = moment(match[1], "YYYY-MM-DD");
                return fechaHeading.isValid() && fechaHeading.isBefore(fechaNota, 'day');
            });

        if (headingsAnteriores.length === 0) {
            dv.paragraph("✅ No hay días anteriores en esta semana.");
        } else {
            let tareasPendientes = sem.file.tasks.where(t => {
                if (t.completed) return false;
                // Excluir hábitos
                if (t.text.startsWith("habito")) return false;
                // Verificar que la sección de la tarea corresponde a un heading anterior
                let subpath = t.section?.subpath || "";
                return headingsAnteriores.some(h => subpath.startsWith(h.substring(0, 10)));
            });

            if (tareasPendientes.length > 0) {
                dv.taskList(tareasPendientes, false);
            } else {
                dv.paragraph("✅ ¡Todo al día, no hay pendientes de días anteriores!");
            }
        }
    } else {
        dv.paragraph("❌ No se encontró la semana: " + nombreSemana);
    }
}
```

```dataviewjs
let hoyStr = dv.current().file.name;

if (hoy.isValid()) {
```

## Cierre del Día

Contexto inicial

Hoy me levante enfermo agripado, con una migraña leve que me azotaba, de esos dias donde dormir y escapar es tentador, he sido el chico que siente que su vida no es interesante, que mis historias pasan desapercibidas 

Llamado
Recorde mi clase diaria de Plazi y abri con pereza la clase de story telling, y como una cachetada una frase simple del profe me cambio la mente "Si hubo un cambio....hay historia", cuantas historias de derrota me contaba? y que tanto despeciba mis victorias?

Aliados 
Fue entonces que con el profe me di cuenta, que si, que mi vida la conte como quien pierde una guerra, olvidando los momentos heroicos, y valientes, exagerando errores como muestras de mi mala identidad, 

Crisis


Transformacción y regreso
Escribire mi historia por que implica un cambio para mi, fue suficiente de esperar a vivir como James bones, para contar mi propio recorrido y mi paso de hoy.


1. ¿Donde estaba?: Cuando era mi turno de contar una historia, siempre me bloqueaba, pensaba que mi vida no era interesante que carecía de historias épicas como la de William Wallace o James Bond

2. ¿Que me hizo darme cuneat que debía cambiar?
   Ello me llevo a mentirle al amor, a Salome le conte de mi "propia empresa" quería impresionarla, me daba mucha vergüenza admitir que no me gustaba mi situación laboral en ese momento,  fue la culpa de mentirle, lo que me llevo iniciar el curso de story telling
   
3. ¿Quien me ayudo a avazar?
   El profesor Daniel explico dos conceptos simples pero poderosos "si hubo un cambio...hay una historia, las historias están hechas para transformar y conectar, no para probar tu valía". Esto me golpeo como una cachetada.

4. ¿Que obtaculos vivi?
	Me di cuenta que yo, durante mucho tiempo he sido mi propio hatter, y que mientras persistiera la creencia de que mi vida era aburrida, siempre mentiría al narrarla. 

 
5. ¿Que cambio en mi?
  Por eso me enfoque en los cambios sutiles del día a día, desde como maneje el enojo con mi jefe, en mi preparación del té, o la reflexión que pensé, me libere de la presión de vivir como en Hollywood para narrar mi propia vida con transparencia y orgullo.
   
6. ¿Que pueod compartir a otros gracias a esta experiencia?
  No es necesario vivir una epica todos los dias para narrar, pues hasta el mas pequeño paso puede guardar sabiduría esperando ser contada.
